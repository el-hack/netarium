# Direction visuelle

L’interface doit être propre, professionnelle, jolie et douce. La douceur repose sur les surfaces, les espacements et les mouvements discrets ; elle ne doit pas rendre les textes illisibles.

- Palette : ivoire pour le fond, blanc pour les surfaces, ardoise pour le texte, sauge pour les actions et ocre pour les observations de cache.
- Hiérarchie : navigation stable, une action principale de découverte, indicateurs séparés, scène exploratoire puis inventaire exploitable.
- Typographie : police système pour une interface sans téléchargement ; sérif italique utilisée seulement comme accent éditorial.
- Géométrie : rayons modérés, bordures fines, ombres limitées. Aucun effet lumineux permanent ni défilement animé.
- Carte : anneaux de périmètre discrets, modèles d’appareils arrondis, répartition déterministe pour un même inventaire, rendu au changement de vue. Les contrôles et l’inventaire fournissent une alternative aux interactions 3D.
- États requis : connexion au service, aucun réseau, aucun appareil, collecte en cours, annulation, erreur, recherche vide et absence de WebGL.
- Adaptation : table et cartes au choix sur bureau, cartes sur mobile, navigation compacte en tablette et menu mobile avec fermeture par Échap et restitution du focus.
- Inventaire : recherche insensible aux accents, filtres d’observation cumulables avec la recherche, tri par nom, IP ou date. Les états vides proposent de réinitialiser les filtres.
- Édition : changements non enregistrés identifiés, protection contre la fermeture accidentelle d’une fiche et retour de sauvegarde dans les réglages. Les instantanés historiques restent en lecture seule.
- Accessibilité : contrastes vérifiés automatiquement, noms accessibles stables, boîtes de dialogue natives, réduction des animations et parcours clavier.

Cette direction est une interprétation de la préférence exprimée, sans copie d’une identité existante. Les vérifications visuelles ont été effectuées sur l’application réelle ; les tests automatisés utilisent des données fictives identifiées comme telles.
